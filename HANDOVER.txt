Tinkerfleet — continue learning and building

Start at README.md. It introduces the application, runs the no-key demo, and
routes readers into a practical learning path.

Read docs/build-an-agent-app.md to follow the construction of a personal agent
application: the model loop, chat state, tools, approvals, local execution,
personalities, coordination, memory, web research, and visible activity.

Run the eleven lessons described in lessons/README.md. Lesson 0 runs the agent
loop with a scripted model; lessons 1-6 use the application's modules; lessons
7-10 add a tool, show SDK approvals, run a small eval, and read a trace. None makes a model
call by default. The native-tool lessons use disposable local fixtures.

Use docs/traces.md to read what each model call sent and received.
Use docs/architecture.md to trace the implementation, docs/capabilities.md to
understand current behavior, and docs/extending.md to build the next feature.
Documentation describes this repository's implementation, not the internals of
other agent products.

Validation commands and the meaning of each kind of evidence are in
docs/testing.md. Run checks on the revision you are changing rather than relying
on an old build report. Every image in docs/screenshots is linked from
README.md, which says whether it came from the demo or a live run. Delete a
screenshot when nothing links to it any more.

Practical boundaries to retain while extending the app:
- The primary coordinates; ordinary bots share enabled capabilities.
- A profile, conversation, run, and memory entry have different lifetimes.
- File edits and local commands require an exact, single-use approval.
- Local commands run with the user's own permissions (see SECURITY.md).
- Turn/call count caps are disabled by default, while token/runtime budgets and
  the fixed command timeout remain. Long-running jobs are an extension area.
- docs/capabilities.md is the one place that lists numeric limits and the
  mode table. Other documents link to it; update it when a limit changes.
- Demo responses are scripted. Do not describe them as live model evidence.
- Persisted conversation views and memories are private local data in
  .tinkerfleet/. Keep that directory, credentials, and personal content out of
  shared source and screenshots.
