Run locally
Install Node.js 24+ and npm, then run npm ci and npm run dev from this directory.
Open http://localhost:4317. Demo mode needs neither an API key nor Docker.
Dependency installation normally requires package-registry network access.
For the built interface, run npm run build followed by npm start.

Teaching and operating limits
The demo is deterministic and does not answer arbitrary coding tasks. Its
approvals advance a scripted scenario; they do not execute commands. The bundled
practice project is deliberately broken, and its tests are separate from the
repository suite. Approved live edits affect the run snapshot, not the source
files. Runs and approvals disappear when the local server restarts.
Read README.md, docs/setup.md, and SECURITY.md before opting into live mode.
