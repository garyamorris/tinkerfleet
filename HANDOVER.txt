Scope
Educational local agent app with a scripted demo, live conversation-only mode,
reusable personas, primary-first Coordinator-created groups, and optional native
workspace tools. Approved edits change real files; commands run with the user's
permissions. The working directory is not a sandbox. Docker is not used.

Run locally
Install Node.js 24+ and npm, then run npm ci and npm run dev from this directory.
Open http://localhost:4317. Demo mode needs neither an API key nor Docker.
Dependency installation normally needs package-registry network access.
For the built interface, run npm run build followed by npm start.

Teaching and operating limits
Demo output is simulated. Live conversation can incur API charges. Workspace
opt-in exposes real local reads and exact-approval writes/commands. Commands use
no shell, do not inherit server secrets, and have time/output limits; these do
not prevent access to broader resources allowed by the user's OS permissions.
Restart retains chat history, cancels unfinished runs, and denies pending
approvals. It does not undo file changes or completed command effects. Source
and child group have separate budgets and stop controls, not an overall cost cap.
Read README.md, docs/setup.md, and SECURITY.md before enabling local tools.
