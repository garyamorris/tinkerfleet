Tinkerfleet build handover — 15 October 2026

Scope
Educational local agent app with a primary Coordinator and ordinary individual
agents defined by name and personality. All agents share enabled local/web tools.
The primary can create agents, message them, or start groups of up to eight
participants. Legacy role fields are compatibility data, not capability gates.
Approved local edits change real files; commands run with the user's permissions.
The selected working directory is not a sandbox. Docker is not used.

Context and limits
Defaults: 12 model calls, 2,048 output tokens per response, 64,000 reported tokens
per run, and 120 seconds. Recent history is bounded to 8,000 characters; long tool
outputs to 4,000 with a notice. Complete tool pairs and exact action arguments
are preserved. A finished answer crossing the usage threshold is retained while
further calls and exhausted-budget function work are blocked. Parent and child
runs have separate budgets and stop controls; there is no overall monetary cap.

Run locally
Use Node.js 24+, npm ci, then npm run dev. Open http://localhost:4317. Demo is
scripted and needs no key. Live model use requires explicit configuration.
Workspace tools are opt-in; installed commands and real edits require exact
approval. See README.md, docs/setup.md, and SECURITY.md.

Persistence and privacy
The local server stores profiles and conversation views in the Git-ignored
.tinkerfleet/conversations.json. Keep it private. Restart preserves history but
cancels unfinished runs and denies pending approvals. It does not undo file or
command effects. Credentials do not belong in source, browser settings, or logs.
