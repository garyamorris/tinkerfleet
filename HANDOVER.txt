Tinkerfleet build handover — 15 October 2026

Scope
Educational TypeScript multi-agent workspace with a no-key scripted demo,
reusable bot personas, named direct/group chats, OpenAI Agents SDK integration,
exact-action approvals, a Docker runner, and six no-key lessons. A conversation
captures its participants, and each run keeps its team and fresh file snapshot.
Profile edits affect new conversations. Start by speaking to the primary
Coordinator; it may select specialists and create a shared group. Users can
visit direct bot conversations and Coordinator-created groups. New user-created
conversations are single-bot only; existing group history is preserved.

Run locally
Install Node.js 24+ and npm, then run npm ci and npm run dev from this directory.
Open http://localhost:4317. Demo mode needs neither an API key nor Docker.
Dependency installation normally needs package-registry network access.
For the built interface, run npm run build followed by npm start.

Teaching and operating limits
The demo has a scripted tiny-project delegation path; greetings stay in the
primary chat. Custom purposes do not create
model intelligence. In live mode, purpose text reaches the assigned SDK agent's
instructions but never grants tools or bypasses approvals. The profile library
is stored in this browser, not synced or encrypted as a secret store. Private
conversation history and drafts persist in .tinkerfleet/conversations.json.
The source primary and a created group have separate per-run budgets. One user
turn can consume two budgets. Stopping the primary does not stop an already-created
group; stop the group explicitly. These limits are not an overall monetary cap.
Restart cancels unfinished work and denies pending approvals; raw SDK state,
grants, and working file snapshots are not restored.
The practice project is deliberately broken. Its tests are separate from this
repository's suite. Approved live edits affect the run snapshot, not source files.
Read README.md, docs/setup.md, and SECURITY.md before enabling live mode.
